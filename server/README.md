# API общего состояния календаря

Хранит одно состояние на всю команду: какие эксперты активны и какие задачи
отмечены выполненными. Страница https://kublitskaya003-stack.github.io/kalendar-komandy/
читает и пишет сюда, поэтому отметки видны со всех компьютеров.

- Railway-проект: `kalendar-komandy-api`, том смонтирован в `/data`, файл `/data/state.json`.
- Переменные: `APP_KEY` — общий ключ (он же вшит в страницу), `DATA_DIR` — по умолчанию `/data`.
- Деплой: `cd server && railway up`.
