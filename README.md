# Календарь команды — контент экспертов

Единый календарь производства контента: по каждому дню видно, **что делает команда** и **что ждём от эксперта**.
Собран из 9 личных контент-календарей экспертов (сводная таблица «СВОД_Контент-календари экспертов»).

**Страница:** https://kublitskaya003-stack.github.io/kalendar-komandy/

## Что внутри

- **По дням** — лента дней: в каждом дне две группы — «Команда делает» и «Ждём от эксперта», с чекбоксами.
- **Неделя** — сетка: эксперты по строкам, дни по столбцам.
- **Месяц** — календарная сетка с цветными точками этапов, клик по дню ведёт в ленту.
- **Эксперты** — карточки: циклы целиком + ограничения (дни голосовых/съёмок, объём, за сколько нужен сценарий, периоды отсутствия).
- Фильтры по этапам, экспертам и ответственному; отметки «выполнено» хранятся в localStorage браузера.

Этапы цикла: Темы (команда) → Голосовые (эксперт) → Сценарий (команда) → Съёмка (эксперт) → Монтаж и публикация (команда).

## Обновление данных

Страница пересобирается **автоматически раз в час**: GitHub Actions (`.github/workflows/update.yml`)
читает сводную таблицу и все личные календари, и если что-то изменилось — коммитит новый
`index.html`, после чего GitHub Pages публикует его.

- Обновить сразу, не дожидаясь часа: вкладка **Actions → «Обновить календарь из Google Таблиц» → Run workflow**.
- Новый эксперт подхватывается сам — достаточно добавить строку со ссылкой в сводную таблицу.
  Кого не включать, задаётся списком `EXCLUDE` в `tools/sync.py` (сейчас там Заикина).
- Периоды отсутствия вытаскиваются из текста в календаре эксперта («Дни/время для съёмки»),
  предупреждения из строк со знаком ⚠ — тоже.

Доступ к таблицам: секрет репозитория `GOOGLE_TOKEN_JSON` — OAuth-токен со единственным
правом `spreadsheets.readonly` (только чтение таблиц, без записи и без доступа к Диску).

Запустить сборку локально:

```bash
python3 tools/sync.py   # берёт ~/google_token_readonly.json или ~/google_token.json
git commit -am "обновление" && git push
```
