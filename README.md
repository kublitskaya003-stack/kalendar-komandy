# Календарь команды — контент экспертов

Единый календарь производства контента: по каждому дню видно, **что делает команда** и **что ждём от эксперта**.
Собран из 9 личных контент-календарей экспертов (сводная таблица «СВОД_Контент-календари экспертов»).

**Страница:** https://kublitskaya003-stack.github.io/kalendar-komandy/

## Что внутри

- **По дням** — лента дней: в каждом дне две группы — «Команда делает» и «Ждём от эксперта», с чекбоксами.
- **Неделя** — сетка: эксперты по строкам, дни по столбцам.
- **Месяц** — календарная сетка с цветными точками этапов, клик по дню ведёт в ленту.
- **Эксперты** — карточки: циклы целиком + ограничения (дни голосовых/съёмок, объём, за сколько нужен сценарий, периоды отсутствия).
- Фильтры по этапам, экспертам и ответственному; отметки «выполнено» хранятся в localStorage браузера.

Этапы цикла: Темы (команда) → Голосовые (эксперт) → Сценарий (команда) → Съёмка (эксперт) → Монтаж и публикация (команда).

## Как обновить данные

```bash
cd tools
python3 dumpall.py     # выкачивает календари экспертов из Google Sheets (нужен google_token.json)
python3 build_data.py  # превращает их в data.json
python3 add_abs.py     # добавляет периоды отсутствия экспертов
python3 build.py       # собирает ../index.html
```

Затем `git commit` и `git push` — GitHub Pages обновится автоматически.
